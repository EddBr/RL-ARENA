Agent in state $s$ interacts with environment using policy $\pi$ to sample action $a\sim \pi (\cdot|s)$

Environment sends -> $(s',r)$ 

New state is sampled from environment transition distribution $s' \sim T(\cdot| s,a)$

Reward $r=R(s,a,s')$

-> Environment and policy are Markovian, their dynamics depend only on **previous** state and action, or on the **current** state

### Trajectory / Rollout
-This is the full history of interaction between the agent and the environment
$\tau =s_0, a_0,r_1, s_1,a_1,r_2,s_2,a_2,...$

# Value Function
Maximise the expected discounted return $G$
$G_t =r_{t+1}+\gamma r_{t+2}+\gamma^2r_{t+3}...$

$V_\pi(s)=E_\pi[G_t|s_t=s]$
$=E_\pi[\sum^\infty_{i=1}\gamma^ir_{i+t+1}|s_t=s]$
$=E_\pi[r_{t+1}+\gamma r_{t+2}+\gamma^2r_{t+3}+...|s_t=s]$
1. Why do we discount? - Because we want earlier decisions to have more weight + we want it to converge
2. Why do we discount geometrically? - Convergence condition? Nah, we could use something else, $t+1$ is worth $1/\gamma$ less than $t$, which is better than other discount functions which converge -> 1
3. Why do both sides not depend on $t$ ($V$ is time invariant)? - The reward function is based off state and action, time is irrelevant
# Bellman Equation
$V_\pi(s)=\sum_a\pi(a|s)\sum_{s'}T(s'|s,a)(R(s,a,s')+\gamma V_\pi(s'))$
**Attempted Proof**
$=E_\pi[r_{t+1}+\gamma r_{t+2}+\gamma^2r_{t+3}+...|s_t=s]$
$=\sum_a\pi(a|s)\sum_{s'}T(s'|s,a)[\sum^\infty_{i=1}\gamma^ir_{i+t+1}]$
$=\sum_a\pi(a|s)\sum_{s'}T(s'|s,a)[r_{t+1}+\sum^{\infty}_{i=2}\gamma^i r_{i+t+1}]$
$=\sum_a\pi(a|s)\sum_{s'}T(s'|s,a)[R(s,a,s')+\sum^{\infty}_{i=2}\gamma^i r_{i+t+1}]$
$=\sum_a\pi(a|s)\sum_{s'}T(s'|s,a)[R(s,a,s')+\gamma V_\pi(s')]$
**Actual Proof**
$=\sum_a\pi(a|s)E_\pi[G_t|s_t=s,a_t=a]$
$=\sum_a\pi(a|s)E_\pi[r_{t+1}+\gamma G_{t+1}|s_t=s,a_t=a]$
Then expand over next states:
$=\sum_a\pi(a|s)\sum_{s'}T(s'|s,a)[R(s,a,s')+\gamma G_{t+1}|s_t=s,a_t=a]$
$=\sum_a\pi(a|s)\sum_{s'}T(s'|s,a)[R(s,a,s')+\gamma E_\pi[G_{t+1}|s_{t+1}=s']]$
$=\sum_a\pi(a|s)\sum_{s'}T(s'|s,a)[R(s,a,s')+\gamma V_\pi(s')]$
$\square$
# Q-Value - Defining the value of an action
$Q_\pi(s,a)=E[\sum^\infty_{i=1}\gamma^ir_{t+i+1}|s_t=s,a_t=a]$
Recursively: $Q_\pi(s,a)=\sum_{s'}T(s'|s,a)[R(s,a,s')+\gamma\sum_{a'}\pi(a'|s')Q_{\pi}(s',a')]$

$V_\pi(s)=E_\pi[G_t|s_t=s]$
$Q_\pi(s,a)=E[\sum^\infty_{i=1}\gamma^ir_{t+i+1}|s_t=s,a_t=a]$

$Q_\pi=V_\pi$? - nO!

$V_\pi(s)=\sum_a\pi(a|s)Q_\pi(s,a)$ - value function is average over possible actions

$Q_\pi(s,a)=\sum_{s'}T(s'|s,a)[R(s,a,s')+\gamma V_\pi(s')]$
# Policies
2 policies are equivalent $\pi_1=\pi_2$ if $V_{\pi_1}(s)=V_{\pi_2}(s)$ for all states $s$
A policy is better than or pareto dominant $\pi_1\ge\pi_2$ if $V_{\pi_1}(s)\ge V_{\pi_2}$ for all states $s$

Optimal policies $\pi^*$
$V^*(s):=\sup_\pi V_\pi(s)$
**Prove that an optimal policy exists**
A metric space of value functions
$V_\pi(s)=\sum_a\pi(a|s)\sum_{s'}T(s'|s,a)(R(s,a,s')+\gamma V_\pi(s'))$

We want to choose the optimal policy

$\max_{a\in\mathcal{A}}\sum_{s'}T(s'|s,a)[R(s,a,s')+\gamma V_\pi(s')]$


1. Improve the value function
2. Improve the policy

# TD Error
$\delta_t:=r_{t+1}+\gamma \hat Q^*(s_{t+1},a_{t+1})-\hat Q^*(s_t,a_t)$

Update with learning rate $\alpha$
$\hat Q^*(s_t,a_t)\leftarrow \hat Q^*(s_t,a_t)+\alpha(r_{t+1}+\gamma \hat Q^*(s_{t+1},a_{t+1})-\hat Q^*(s_t,a_t))$

This requires $(s_t,a_t,r_t,s_{t+1},a_{t+1})$ - SARSA!
# SARS
## On-policy
Only learns from data that was actually generated by the current policy $\pi$
$\pi(s)=\arg\max_a\hat Q^*(s,a)$

Improving policy + improving Q-function
# $Q$-Learning 
Can learning optimal $Q$-value $Q^*$ for any policy $\pi$
## Off-policy

# $TD(\lambda)$
SARSA is a 1-step update $Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha(r_{t+1}+\gamma Q(s_{t+1},a_{t+1})-Q(s_t,a_t))$

Temporal Difference of 1 ($TD(1)$)

2-step TD update $TD(2)$ would look like:
$Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha(r_{t+1}+\gamma r_{t+2} +\gamma^2 Q(s_{t+2},a_{t+2})-Q(s_t,a_t))$

Shorter updates $\delta_{t:t+1}$ have less variance as they rely on fewer samples, 

BUT might have a systemic bias as we replace the tail of the return with our current best guess $\gamma Q(s_{t+1},a_{t+1})$

We could do a weighted assortment $\frac 1 2 \delta_{t:t+1}+\frac 1 2 \delta_{t:T}$
Or $\sum^{T-t}_{i=1}\theta_i=1$ and $\theta_i\ge0$

Choose the weights $\theta_{t+k}=(1-\lambda)\lambda^{k-1}$ for $k=1,...,T-t$
$G^\lambda_t=(1-\lambda)\sum^{T-t}_{k=1}\lambda^{k-1}G_{t:t+k}+\lambda^{T-t}G_t$ for terminating environments

$TD(\lambda): Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha(G_t^\lambda-Q(s_t,a_t))$

## Problems with $TD(\lambda)$
1. Computing $G_t^\lambda$ is expensive - $O(T^2)$
2. Must wait til end of episode to update -- doesn't work in continuous environments!
## FIX: Eligibility trace $e_t(s,a)$
Measures how we should 'blame' a state-action pair on $t$
$e_0(s,a)=0$
$e_t(s,a)=\gamma \lambda e_{t-1}(s,a)+1(s=s_t,a=a_t)$

### Pros of Eligibility traces
Good when rewards are delayed and paths are long
